Acerca de EcoAprende

Objetivo: ofrecer información y actividades para fomentar el cuidado del medio ambiente entre estudiantes y familias.

¿Por qué es importante? La contaminación y el desperdicio de recursos afectan a los ecosistemas. Aprender buenos hábitos ayuda a tomar decisiones responsables.

Herramientas utilizadas: HTML para la estructura, CSS para el diseño adaptable y JavaScript para los botones y el cuestionario.

Conclusión: la tecnología puede ayudar a compartir información ambiental y motivar cambios positivos. Cada persona puede contribuir con acciones sencillas.
